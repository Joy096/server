# main.sh — общее меню скриптов Joy096/server

Одно меню, из которого запускаются все скрипты репозитория. Каждый пункт скачивает свежую версию нужного скрипта с GitHub во временный файл, запускает его, а после выхода из него возвращает в меню.

## Запуск

```
wget -O main.sh https://raw.githubusercontent.com/Joy096/server/refs/heads/main/main.sh && bash main.sh
```

Запускать можно и без root: нужные права проверяет каждый скрипт сам.

## Как это работает

- Список пунктов — массив `ITEMS` в начале скрипта, строки вида `"Раздел|Название|файл.sh"`. Номера считаются сами по порядку строк, заголовок раздела печатается, когда раздел меняется.
- Скачивание: `curl`, если его нет, то `wget`. Перед запуском проверяется, что файл не пустой и начинается с `#!...bash`; иначе показывается сообщение с ссылкой и меню остаётся на месте.
- Скрипт запускается как `bash <временный файл>` и после выхода временный файл удаляется. Скрипты, которые удаляют сами себя (`server_new.sh`, `adguard_home.sh`, `x-ui.sh`, `outline_vpn.sh`, `hysteria.sh`, `lampa.sh`), работают так же, как при запуске вручную.
- После выхода из скрипта сразу показывается общее меню (вопроса «Нажмите Enter» нет, убран 24.11.2026 по просьбе Vitalii). Пустой ввод в меню просто показывает его заново; неверный пункт даёт сообщение.
- Переменная `SERVER_BASE_URL` (необязательно) заменяет адрес репозитория; нужна для тестов (`file://…`).

## Правило обновления (решение Vitalii 24.11.2026)

Когда в репозиторий добавляется новый скрипт, которого ещё не было, в `main.sh` добавляется его строка в `ITEMS` (подходящий раздел, понятное название на русском), обновляется эта таблица, и оба файла сохраняются в проект и в GitHub. То же при переименовании или удалении скрипта.
