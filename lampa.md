# lampa.sh: Lampa (веб-версия) + nginx, установка, автообновление, удаление

Интерактивный скрипт для Ubuntu/Debian. Запуск: `sudo bash lampa.sh` (скачивается с GitHub `Joy096/server`, файл после выхода сам себя удаляет: `trap ... rm -f "$SCRIPT_PATH"`). До 03.11.2026 описания в проекте не было; добавлено при внедрении удаления по компонентам. Интерфейс только на русском.

## Что делает
- Ставит пакеты `git nginx curl wget ca-certificates`, клонирует готовую сборку Lampa (`https://github.com/yumata/lampa.git`) в `/opt/lampa`, копирует файлы в `/var/www/lampa`.
- Настраивает **системный nginx**: сайт `/etc/nginx/sites-available/lampa` (ссылка в `sites-enabled`), порт спрашивается (по умолчанию 80, занятые порты не принимаются), заголовки CORS «*». Ссылку `sites-enabled/default` при установке удаляет.
- Открывает порт в UFW (если UFW активен) с комментарием `Lampa HTTP`.
- Ставит задачу cron «ежедневно в 3:00» (маркер `# LAMPACRON_GITHUB_AUTOUPDATE`): `curl ... lampa_update.sh | bash > /root/lampa_update.log`. `lampa_update.sh` лежит в репозитории рядом (обновляет `/opt/lampa` и копирует в `/var/www/lampa`).
- Пункт 4 меню скачивает и запускает `torrserver.sh` (`wget -O torrserver.sh "$TORRSERVER_SCRIPT_URL"`: с 03.11.2026 новый файл записывается поверх старого; раньше без `-O` при существующем `torrserver.sh` в текущей папке `wget` сохранял новый как `torrserver.sh.1`, а запускался старый).

## Меню
1. Установить / Переустановить Lampa. При переустановке вызывается `uninstall_lampa_internal` (всё, кроме пакетов, без вопросов).
2. Удалить Lampa (всё или по компонентам): `uninstall_lampa`.
3. Показать адрес сервера Lampa.
4. Torrserver (установка/управление).
0. Выход.

## Учёт установки (с 03.11.2026)
Файл состояния `/etc/lampa-setup.state`: строка `PKGS_ADDED=` с пакетами, которых не было до установки Lampa (проверка `dpkg-query` до `apt install`). Только по ним удаление предлагает убрать пакеты. Если Lampa поставлена прежней версией скрипта, файла нет: пакеты не отслеживались, при удалении выводится подсказка переустановить Lampa (пункт 1), тогда учёт появится.

## Удаление (пункт 2)
Показывает найденное и даёт выбор: 1 всё / 2 по компонентам / 0 отмена. Компоненты:
- сайт Lampa в nginx (`rm_lampa_site`; если nginx остаётся, делает `nginx -t`, `reload` и при необходимости запускает службу);
- файлы Lampa (`/var/www/lampa`, `/opt/lampa`);
- автообновление (cron и журнал `/root/lampa_update.log`);
- правило UFW (находится по комментарию `Lampa HTTP`, удаляется `ufw delete allow N/tcp`; чужие правила без этого комментария не трогаются);
- пакет `nginx` (только если его поставил скрипт), с проверкой «используют ли его другие программы» (см. ниже);
- остальные пакеты, поставленные скриптом (обычно `git`): `apt-get purge`, затем показ списка `autoremove` и вопрос.
Зависимость: если выбран пакет nginx, сайт Lampa удаляется вместе с ним. Перед удалением итоговый список и вопрос `[y/N, Enter = N (нет)]`.

## Правило «nginx используют другие программы» (общее для скриптов проекта)
Перед удалением пакета nginx скрипт вызывает `nginx_other_users` и, если что-то найдено, показывает список, предупреждает и спрашивает подтверждение (Enter = нет, оставить). Что считается «использует nginx»: сайт Lampa (`sites-enabled/lampa`), HTTPS Jackett (служба `jackett-tls`, `/etc/jackett-cert/nginx.conf`), другие файлы в `sites-enabled` (кроме `default`) и `conf.d/*.conf`, установленные пакеты с зависимостью от nginx (`apt-cache rdepends --installed nginx`, кроме самих `nginx*`/`libnginx*`, например `python3-certbot-nginx`), запущенная служба `nginx` (если ничего другого не найдено). Из списка исключается то, что удаляется сейчас. Те же функции (`nginx_other_users`, `purge_nginx_checked`) стоят в `ssl.sh` (удаление HTTPS Jackett), `jackett.sh` (удаление HTTPS-прокси) и здесь.

## Исправление в этой версии
Определение порта из конфига nginx раньше не работало: в `grep`/`sed` стояли двойные обратные слэши (`'^\\s*listen...'`), и порт всегда был пуст. Из-за этого пункт 3 писал «порт не определен», а правило UFW при удалении не убиралось. Теперь порт берётся через `awk` (`lampa_port`), UFW удаляется по комментарию.

## Что не менялось
Установка (порт, клон, nginx, UFW, cron), остановка nginx в начале установки, удаление `sites-enabled/default`, пункт 4 меню.
